Project Overview & Objectives

Modern high-availability network infrastructures require rapid fault mitigation. Human intervention in link outages, bandwidth saturation, or distributed denial-of-service (DoS) attacks introduces severe operational latency.

Autonomous Network Engineer (ANE) implements an automated, self-driving feedback loop. It synthesizes streaming network telemetry with a dual-stage machine learning pipeline to detect, classify, and remediate faults in real time without human manual configuration.

🔀

Network Architecture & Failover Topology

The monitored network topology consists of dual LAN subnets bridged by three interconnected edge routers (r1, r2, r3) maintaining primary and standby routes:

🛡️ Quarantine at Gateway: Attacks originating at h4 (10.0.1.14) are dropped directly at router r1 using forward-chain packet filtering, protecting link capacity.

🛡️

Engine Safety & Resiliency Controls

  • Transient Spike Suppression: Faults must persist across multiple polling epochs (confirm_n=2) to avoid triggering on temporary network jitter.
  • Closed-Loop Verification: After action execution, three consecutive verification samples are collected. If metric recovery fails, the change is instantly rolled back.
  • Auto-Expiring Blocks (TTL=600s): Quarantined IPs auto-expire to ensure no host is permanently isolated from false alarms.
  • Automated Failback: Active probe threads periodically test the primary path. Once recovered, traffic safely returns to primary.
🧠

Machine Learning Classification Pipeline

ANE employs a collaborative two-tier machine learning architecture:

Tier 1: Isolation Forest (Unsupervised): Detects zero-day anomalies and unexpected network behavioral shifts without requiring predefined failure signatures.

Tier 2: Random Forest Classifier (Supervised): Categorizes verified anomalies into specific remediation classes with high precision and recall.
